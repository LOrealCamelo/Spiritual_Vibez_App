# Header and wordmark preview

These screenshots show the proposed Web header and home welcome area on the
`preview/hero-wordmark` branch. This preview does not update the live Render site.

- [Desktop header](header-wordmark-desktop.png), captured at a 1448px viewport.
- [Phone website](header-wordmark-phone.png), captured at a 390px viewport.

The original white-shirt illustration appears in full in the upper-left circle,
including her hips. The home welcome box now contains the Spiritual Vibez name,
the Zodiac, Tarot & More tagline, and a single-line journey heading. Spiritual
uses DM Sans; Vibez uses pink Pacifico lettering, crisp offset shadows, and gold
vibration arcs. Action buttons use DM Sans and vector icons without text glow.

Browser checks covered 1448, 1024, 800, 390, and 320px widths with no horizontal
overflow or JavaScript errors. The desktop heading stays on one line. Existing
Web asset tests and the native TypeScript check pass. Native changes in this
preview only remove blurred heading shadows; the screenshots show the website.
